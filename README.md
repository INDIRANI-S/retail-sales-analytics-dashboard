# Retail Sales Data Cleaning and Analysis

## Project Overview

This project focuses on cleaning, validating and analysing retail sales data using Microsoft Excel. The objective was to improve data quality, identify inconsistencies and generate meaningful business insights through exploratory data analysis.

---

## Objectives

- Clean and prepare raw retail sales data.
- Validate data for accuracy and consistency.
- Identify missing values, duplicates and data errors.
- Analyse sales patterns and product performance.
- Generate business insights from the cleaned dataset.

---

## Tools Used

- Microsoft Excel
- Excel Functions
- Data Validation
- Sorting & Filtering
- Pivot Tables

---

## Project Activities

- Cleaned and standardized raw sales data.
- Removed duplicate records and corrected inconsistencies.
- Validated data using Excel tools and functions.
- Performed exploratory sales analysis using Pivot Tables.
- Summarized key findings to support business decision-making.

---

## Key Insights

- Improved data quality for reliable analysis.
- Identified sales trends across products and categories.
- Analysed customer purchasing patterns.
- Produced clean, analysis-ready datasets.
